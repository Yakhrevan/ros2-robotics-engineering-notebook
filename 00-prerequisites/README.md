# 00 — Prerequisites

You already know some ROS 2 application concepts, so do not spend excessive time here.

Focus on gaps that directly affect ROS internals.

## Linux

Learn:
- processes
- threads
- scheduling
- memory
- IPC
- shared memory
- sockets
- permissions
- udev
- systemd
- networking

Useful:
- Linux man pages: https://man7.org/linux/man-pages/
- Linux kernel docs: https://docs.kernel.org/

## C++

Learn:
- pointers/references
- RAII
- smart pointers
- STL
- templates
- move semantics
- threads
- mutexes
- atomics
- futures
- condition variables
- CMake

ROS C++:
https://github.com/ros2/rclcpp

## Networking

Primary open textbook:
https://cnp3book.info.ucl.ac.be/

Learn:
- Ethernet
- ARP
- IP
- subnetting
- routing
- UDP
- TCP
- multicast
- sockets
- firewall

Tools:
https://www.wireshark.org/
https://www.tcpdump.org/

## Mathematics

Learn enough to understand:
- TF
- SLAM
- estimation
- control

Topics:
- linear algebra
- rotations
- quaternions
- coordinate transforms
- probability
- Bayes
- optimization
