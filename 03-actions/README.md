# 03 — ROS 2 Actions

Learn to create actions yourself.

Example:

```text
# Goal
float64 target_x
float64 target_y
---
# Result
bool success
string message
---
# Feedback
float64 distance_remaining
```

Study:
- .action interface
- generated Goal/Result/Feedback
- action server
- action client
- goal handle
- acceptance/rejection
- feedback
- result
- cancellation
- concurrency
- action QoS
